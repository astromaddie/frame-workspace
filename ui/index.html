Frame Control sends anonymous usage statistics: that it was installed and opened, its version, your operating system, your country (from the computer's time zone setting), which tabs you use, whether installs on the Frame worked, and how many headsets you use (a one-way hash of each headset's machine ID, the same on every computer, so they're counted once). VR comfort and performance

Waiting for the Frame
Compositor FPS measures SteamVR output, not game FPS. Application FPS is unavailable when no app supplies timing. GPU time is render time, not GPU utilisation. Temperature is the hottest readable sensor.
The HUD is ours and uses the Frame’s built-in tools. Place its panel with SteamVR’s Float in World or controller docking controls. It updates every two seconds until closed.

Playspace and seated comfort

Tracking-origin controls are not available yet: reversible changes still need an idle-headset test. Use SteamVR’s recenter and room setup for now. A seated origin only affects apps that use seated tracking; it cannot force a game into seated mode.

For motion comfort, choose snap-turn, teleport movement and a movement vignette in each game’s settings. SteamVR has no verified universal snap-turn or locomotion-vignette switch.

How sessions and alerts work

This is a reminder, not a parental lock. The timer continues on the Frame if you disconnect; a headset restart cancels it. Cancel before changing settings. Set break/check-in to 0 to turn them off.

Battery, heat and check-in alerts appear on connected companions during a session. Headset warnings and break reminders continue without a companion. iOS may suspend phone notifications in the background. Breaks and check-ins count SteamVR activity, not confirmed wear time.

Import from my Quest

Plug your Quest into this computer by USB, put it on, then Look for my Quest.
Copies games you own from your own Quest (developer mode on) to the Frame. A game with OBB data takes two imports: the first installs it; start it from the Steam library, then import again to copy its data in. Frame Control never starts the game itself. Games that use Meta's licence check install with a warning: on the Frame that check can't reach Meta, so they may quit, hang, or run without online features. Frame Control won't remove that check. How it works

My Meta library

Experimental
Off. Nothing is sent to Meta until you connect.

Experimental. This uses Meta's undocumented internal API with your own Meta access token. It may stop working whenever Meta changes things, and using it may be against Meta's terms; your account is your responsibility. It only lists and downloads games your account owns, installs them as they are, and never removes a licence check.

or paste your token:
How to get your token. Sign in with Meta (desktop app) opens Meta's login page in its own Frame Control window and takes the token from there; it never reads your browser. Frame Control checks it with Meta, then keeps it in a private file on this computer (never on the Frame, and never in reports). Disconnect deletes it.
Install downloads the game from Meta and installs it like Import from my Quest; a game with OBB data takes a second Install while it is open. Install and test also starts it, adds its data, watches it for about 30 seconds and records whether it ran; Test again does just the test.
