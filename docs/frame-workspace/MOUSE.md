## Runtime wiring

- A single dedicated control WebSocket runs independently of video queues through the existing tunnel. One ticket is issued per workspace Start, before concurrent panel launches. Ready binds session/host epochs, panel generations, current input epochs, selected stamps and actually submitted recovery controls. Capture only starts after ready. Tickets expire in 60 s; an accepted connection without readiness restores locally after 30 s. Reconnect is idle and requires fresh Start.
- The existing active `SpatialCursorFence` CGEvent tap consumes untagged physical mouse events before its old 50 ms observer throttle. Tagged injected events pass through; captured events never claim competing external ownership. Mac keyboard remains native. Captured ownership suppresses the Mac cursor in the shared capture.
- Cumulative absolute motion snapshots coalesce only next to other motion snapshots. Button edges/wheel order survive. Epochs/sequences reject replay. Host consumes packets each frame and binds newly ready panels on the same socket; acknowledged binding revisions retry safely. A closing panel is retired from bindings without canceling other valid panels; losing the last binding stops capture.
- Lease TTL is 1.5 s with 250 ms heartbeats. An independent 50 ms Mac timer releases even if no events arrive. Host heartbeat ACK and render-loop watchdogs stop failed connections. Tap disable, disconnect, invalid readiness, queue/backpressure failure, tracking loss or last-window closure cancel held input and unsaved placement. No capture restart or old gesture replay occurs.
- Work uses one world-space pointer point. Head turn/lean alone cannot move it; physical motion crosses surface intersections, retaining the last interaction depth in empty space. Hover only highlights/wakes, without focus. Click/scroll reuse ContentInput's existing focus ACK, geometry validation, release and cancellation. Held drags retain their original target, clamped at its content edge. Gaze dwell is 1.2 s after at least 1 s mouse idle; activity, held input, Arrange, menus and placement reset/suppress it. Focus ACK returns actual restored per-window UV. A token/motion-sequence guard permits the remembered-position snap only for that gaze request and only if no newer input is applied or queued; focus acknowledgement itself remains intact.
- Hover is prioritized immediately after focus in the existing budget coordinator, bypassing candidate/residency delay while preserving the cap. The existing 10 Hz switcher monitor coalesces source-change wakeups into the same supervisor; its 1 s periodic pass remains fallback. No hover focus request or direct stream-live bypass exists. The quality badge consumes actual helper `budget.limited` stats.
- Arrange is persistent. Title drag uses a frozen head-facing plane; corners use signed aspect-locked, opposite-corner anchored resizing at fixed depth; depth uses the captured head-to-window ray and preserves physical size. Gesture motion uses a frozen origin so head movement cannot alter a pending placement. Wall placement updates are suspended only for the gesture, preserving membership on cancel. Rotation/curvature are explicit clicks. Bulk layout is labeled Auto-layout.
- Button release saves the final pose atomically. Right-click or releasing over visible Cancel restores the start pose without saving. Wheel-only depth is one transaction, committed once after 250 ms wheel idle. Its placement ray freezes at the first wheel event, so moving the pointer toward recovery controls cannot change depth; only subsequent wheel deltas contribute. The independent live pointer ray still hits Cancel/Recenter/Return. Cancel/control loss before completion restores the start. Recenter window cancels a pending gesture, uses the existing selected-window recenter while preserving width/bend, and recenters the pointer; unrelated layouts stay unchanged. Offscreen-pointer clicks cancel/recenter only, never Mac-click; a directional beacon stays visible.
- Workspace menu exposes Add window, Recenter window, Cancel and Return to Mac. Return to Mac immediately stops the control lease, releases input and invokes the existing local Mac stream shutdown/Spatial restore. The host also writes a session-bound `workspace_stop` and reuses the dashboard's bounded local exit helper (`workspace_exit.hpp`, extracted without behavioral changes), retiring Frame host, dashboard and scene owners independently of the Mac job queue. The companion's normal stop path reconciles/restores state afterward.
